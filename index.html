电导率 (EC) 计算与补偿公式

一、基础物理换算

1. 等效电阻与电导率转换： 在基准温度下，根据电极常数 Kcell 和等效模拟阻值 Rsim 计算溶液在当前温度下的实际电导率 Kt：

Kt = (Kcell / Rsim) × 106
实时计算过程
Kt = (1.0 / 20000 Ω) × 106 Kt = 50.00 μS/cm

2. 物理电阻率： 电阻率 ρt 与实际电导率 Kt 互为倒数关系：

ρt = 1 / (Kt × 10-6)
实时计算过程
ρt = 1 / (50.00 × 10-6) ρt = 20.00 kΩ·cm

二、温度补偿与浓度换算

3. 温度系数补偿（参考 25°C）： 基于线性温补公式，计算从测试温度 ttest 补偿回 25°C 时的基准电导率 K25：

K25 = Kt / [1 + (α / 100) × (ttest - 25)]
实时计算过程
K25 = 50.00 / [1 + (2.00 / 100) × (25.0 - 25)] K25 = 50.00 μS/cm

4. TDS (总溶解固体) 换算： 将补偿后的基准电导率 K25 乘上换算系数（TDS Factor）得到 TDS 值：

TDS (ppm) = K25 × TDS_Factor
实时计算过程
TDS = 50.00 × 0.50 TDS = 25.0 ppm

5. 盐度 (Salinity) 经验换算： 基于电导率 Kt（单位换算为 mS/cm）进行非线性分段经验公式拟合计算。

pH 计算与 Nernst 温度补偿公式

一、能斯特 (Nernst) 响应原理

1. 能斯特响应斜率 (S)： 玻璃电极的理论电位输出随温度而改变，其 Nernst 斜率 S 在不同温度 ttest (°C) 下为：

S = (R · T / F) · ln(10) · 1000 ≈ 0.198416 × (ttest + 273.15)
实时计算过程
S = 0.198416 × (25.0 + 273.15) S = 59.16 mV/pH

2. 能斯特电势公式： 以 pH 7.00 (中性零电点) 为参考基准，等效输出电势 mVsim 与实际 pHtest 的理论对应关系为：

mVsim = (7 - pHtest) × S
实时计算过程
mV = (7 - 7.00) × 59.16 mV = 0.0 mV

二、介质自身温度系数补偿

3. 介质 pH 随温度的漂移公式： 溶液（特别是缓冲液）自身的 pH 随温度而改变。已知基准 25°C 时的 pH 值为 pHref，在其测试温度 ttest 下的实际 pHtest 为：

pHtest = pHref + αph × (ttest - 25)
实时计算过程
pHtest = 7.00 + (-0.005) × (25.0 - 25) pHtest = 7.00 pH

4. H+ 离子浓度换算： 溶液的氢离子活度（浓度）与 pH 呈负对数关系：

[H+] = 10-pHtest
实时计算过程
[H+] = 10-7.00 [H+] = 1.00e-7 mol/L
