# EC / pH 传感器仿真与 Modbus 解析

使用浏览器打开 `index.html`，或在项目目录运行 `npx serve . -l 3000` 后访问本地页面。图表与公式分别从 CDN 加载 Chart.js 和 KaTeX；断网时计算与报文解析仍可使用，图表和公式排版可能不可用。

电导率使用以 25°C 为基准的线性温补：`Kt = K25 × [1 + α(T − 25)/100]`。阻值或当前温度电导率是输入，程序反算 `K25`；当前温度电阻率由 `Kt` 计算，TDS 与盐度由 `K25` 估算。温补因子必须为正。线性温补、固定 TDS 系数及内置盐度插值表都依赖溶液类型和使用温区；盐度表仅在 0～500000 μS/cm 内插值，超出范围不外推。该表没有可追溯的标准来源，不应直接作为计量结果。

pH 的斜率一/二是无量纲电极斜率系数 K1/K2，默认都是 1.000（理想电极），偏移一/二 B1/B2 默认 0 mV。三个在标定温度下测得的缓冲液点按 pH 排序，相邻两点分别求实测斜率（mV/pH）与偏移，再用标定温度下的理想斜率归一化：`S_ideal(t) = 59.16 × (t + 273.15)/298.15 mV/pH`，`Ki = S_i,cal/S_ideal(t_cal)`。四个参数也可手工修改。测试时使用 `S_i,test = Ki × S_ideal(t_test)` 和 `mV = Bi + (7 − pH) × S_i,test`；偏移和原始 mV 保持不变。已标定时修改标定温度或缓冲液点会重新求 K1/K2，修改测试温度会按该温度重新计算 pH。手工输入的 K1/K2 是相对理想斜率的固定倍数。旧版保存的 mV/pH 斜率会自动转换成系数。实际样品 pH 随温度的变化需另行测量。`10⁻ᵖᴴ` 是氢离子活度的浓度近似值。

Modbus 解析支持 RTU 和 TCP 的常见读写功能码、异常响应，以及 16/32 位数据的字节序转换。RTU 会显示 CRC 校验结果；TCP 会检查 MBAP 协议标识符和长度。十六进制输入可以用空格、逗号、分号、冒号、下划线或连字符分隔。

参数只有在点击本地存储提示的“接受全部”后才保存到浏览器；点击“拒绝”会清除此前保存的参数。项目没有后端，也不与物理设备通信。
